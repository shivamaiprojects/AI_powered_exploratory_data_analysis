# AI-Powered EDA Agent

An AI agent that automates exploratory data analysis — dataset profiling,
missing-value and outlier detection, bias assessment, and visualization —
by translating natural-language questions into Python analysis.

**Stack:** Llama 4 Scout · LangChain · Pandas · Plotly · Streamlit · FastAPI · Docker

## Status
Under active development. See `docs/` for module notes.

## Setup
```powershell
py -3.13 -m venv .venv
.venv\Scripts\Activate.ps1
pip install -e ".[dev]"
```
